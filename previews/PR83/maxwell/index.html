Frequency-domain Maxwell

MaxwellModel is a separate entry point from the PDESystem front end: it assembles the time-harmonic electric-field equation directly with Ferrite, using lowest-order Nédélec edge elements (Nedelec{RefTetrahedron, 1}) on a tetrahedral mesh. With fields varying as exp(+iωt), it solves

\[\nabla \times \left(\mu_r^{-1} \nabla \times \mathbf{E}\right) + i\omega\mu_0\sigma\mathbf{E} - \omega^2\mu_0\varepsilon_0\varepsilon_r\mathbf{E} = -i\omega\mu_0\mathbf{J},\]

with n × E = 0 on the perfectly conducting (PEC) facet sets. Materials are assigned per cell set, as FerriteGmsh.togrid produces them from Gmsh physical groups; unnamed cells are vacuum. A passive lossy dielectric has εr = ε' - iε'' with ε'' ≥ 0.

using FiniteElementMethod, Ferrite
grid = generate_grid(Tetrahedron, (8, 8, 8), Vec(0.0, 0.0, 0.0), Vec(1.0, 1.0, 1.0))
addcellset!(grid, "substrate", x -> x[3] <= 0.25)
model = MaxwellModel(
    grid; materials = Dict("substrate" => MaxwellMaterial(; eps_r = 4.4 - 0.08im)),
    pec = ["left", "right", "bottom", "top", "front", "back"], length_scale = 1.0e-2,  # mesh in cm
)
sol = solve_driven(model, 2π * 5.0e9, x -> [0.0, 0.0, exp(-sum(abs2, x .- 0.5) / 0.01)])
field_values(sol, [Vec(0.5, 0.5, 0.5)]).E

The system matrix is a sum of real sparse blocks on one sparsity pattern, each with a complex coefficient that is a function of ω, so a frequency sweep only recombines nonzero values with maxwell_operator!, and further terms (boundary conditions, ports) are added as blocks with FiniteElementMethod.add_term!.

Wave ports, absorbing boundaries and frequency sweeps

Rectangular-waveguide ports and first-order absorbing boundaries are model keywords. A WavePort on a planar boundary facet set launches and absorbs the TE10 mode of the rectangle it spans; a_direction names the broad wall. Facet sets in absorbing get the first-order Silver-Müller condition n × (μr⁻¹ ∇ × E) = -i k0 sqrt(εc/μr) n × (n × E) (εc = εr - iσ/(ωε0) of the adjacent material), exact for a plane wave at normal incidence (a TE10 wave reflects Γ = (β - k0)/(β + k0) from it). solve_sweep returns the scattering matrix at each angular frequency; it keeps one operator matrix and one factorisation pattern, and solves every port's excitation from a single factorisation per frequency. The linear solver is the solver keyword (see FiniteElementMethod.umfpack_solver).

using FiniteElementMethod, Ferrite
# A 50 mm section of WR-90 (22.86 mm × 10.16 mm), mesh in millimetres.
grid = generate_grid(Tetrahedron, (16, 7, 34), Vec(0.0, 0.0, 0.0), Vec(22.86, 10.16, 50.0))
ports = [WavePort("bottom"; a_direction = (1, 0, 0)), WavePort("top"; a_direction = (1, 0, 0))]
model = MaxwellModel(grid; pec = ["left", "right", "front", "back"], ports, length_scale = 1.0e-3)
sweep = solve_sweep(model, 2π .* (8.0e9:0.5e9:12.0e9))
sweep.S[2, 1, 5]  # S21 at 10 GHz: |S21| ≈ 1, angle ≈ -93.3°

Sᵢⱼ is referred to the port faces, or to planes deembed mesh units inside them. Ports on different guides are normalised to power waves through the TE10 wave impedance ωμ0μr/β. Below cutoff the propagation constant is β = -iα, the evanescent branch.

From a PDESystem

FEMDiscretization(Ω, t; omega, spaces = Dict(E => Nedelec{RefTetrahedron, 1}())) discretizes the time-domain equation curl(ν curl E) + a₂ ∂ₜ²E + a₁ ∂ₜE + a₀ E = f for a vector unknown E at the angular frequency omega, and discretize returns the complex LinearProblem that driven_problem builds for the equivalent MaxwellModel (in units with ε0 = μ0 = 1). The operator is written with curl and the perfect conductor with facet_normal, which needs a PDEBase with facet normals.

using FiniteElementMethod, Ferrite, ModelingToolkit, DomainSets, LinearAlgebra, LinearSolve
grid = generate_grid(Tetrahedron, (8, 8, 8), Vec(0.0, 0.0, 0.0), Vec(1.0, 1.0, 1.0))
Ω = MeshDomain(grid)
@parameters x y z t
@variables E(..)[1:3]
X, Ev, Dt = (x, y, z), [E(t, x, y, z)[c] for c in 1:3], Differential(t)
cc = curl(curl(Ev, X) / 2, X)    # μr = 2
eqs = [cc[c] + 4 * Dt(Dt(Ev[c])) + 0.1 * Dt(Ev[c]) ~ (c == 3) * exp(-10 * ((x - 0.5)^2 + (y - 0.5)^2)) for c in 1:3]
pec = reduce(vcat, [cross(facet_normal(Γ), [E(t, Γ)[c] for c in 1:3]) .~ 0 for Γ in boundarypieces(Ω)])
@named sys = PDESystem(eqs, pec, [t ∈ Interval(0.0, 1.0), (x, y, z) ∈ Ω], [t, x, y, z], [E(t, x, y, z)])
disc = FEMDiscretization(Ω, t; omega = 2.0, spaces = Dict(E => Nedelec{RefTetrahedron, 1}()))
sol = solve(discretize(sys, disc))
(; model, omega) = maxwell_model(sys, disc)
field_values(MaxwellSolution(model, omega, sol.u), [Vec(0.5, 0.5, 0.5)]).E

Coefficients are real, so a complex permittivity ε' - iε'' is only available on the operator-level MaxwellModel.

Absorbing boundaries, ports and sweeps

The first-order absorbing condition is written in its time-domain form, n × (ν ∇ × E) = -sqrt(ε/μ) n × (n × ∂ₜE) with ε = a₂ and ν = 1/μ of the cells next to the piece. With ∂ₜ = iω and ε0 = μ0 = 1 this is the model's n × (μr⁻¹ ∇ × E) = -i k0 sqrt(εr/μr) n × (n × E), so the piece goes to absorbing. Any equivalent set of equations is accepted; at the actual normal of every facet the conditions must span exactly the two tangential equations of this one, and a different coefficient of curl E, a different impedance, the opposite sign or an added term is an error. The cells next to the piece must be lossless (a₁ = a₀ = 0); a lossy one has no time-domain form here and needs MaxwellModel's absorbing keyword.

A WavePort is modal data rather than a local condition, so ports are the ports keyword of FEMDiscretization, on pieces without a condition in the PDESystem. discretize treats them as matched terminations of the source problem; solve_sweep(pdesys, disc, omegas) drives them and returns the scattering matrices, as solve_sweep(maxwell_model(pdesys, disc).model, omegas) does. With ports a₀ must be zero, so that the model does not depend on omega, and a sweep rejects a volume source.

grid = generate_grid(Tetrahedron, (12, 6, 15), Vec(0.0, 0.0, 0.0), Vec(22.86, 10.16, 30.0))  # WR-90, mm
Ω = MeshDomain(grid)
n, Eb = facet_normal(boundarypiece(Ω, :top)), [E(t, boundarypiece(Ω, :top))[c] for c in 1:3]
abc = cross(n, curl(Eb, X)) .~ -cross(n, cross(n, Dt.(Eb)))
pec = reduce(vcat, [cross(facet_normal(Γ), [E(t, Γ)[c] for c in 1:3]) .~ 0 for Γ in boundarypiece.(Ref(Ω), [:left, :right, :front, :back])])
eqs = [curl(curl(Ev, X), X)[c] + Dt(Dt(Ev[c])) ~ 0 for c in 1:3]
@named sys = PDESystem(eqs, [pec; abc], [t ∈ Interval(0.0, 1.0), (x, y, z) ∈ Ω], [t, x, y, z], [E(t, x, y, z)])
k0 = 2π * 10.0e9 / FiniteElementMethod.C0 * 1.0e-3  # 10 GHz in rad/mm
ports = [WavePort(boundarypiece(Ω, :bottom); a_direction = (1, 0, 0))]
disc = FEMDiscretization(Ω, t; omega = k0, spaces = Dict(E => Nedelec{RefTetrahedron, 1}()), ports)
solve_sweep(sys, disc, k0 .* [0.8, 1.0, 1.2]).S  # |S11| ≈ 0.14 at 10 GHz, the reflection of the absorbing end

FiniteElementMethod.maxwell_model — Function
maxwell_model(pdesys::PDESystem, disc::FEMDiscretization) -> (; model, omega, load)

The MaxwellModel, angular frequency and load vector that discretize(pdesys, disc) builds for a disc with omega, so that the solution u of its LinearProblem can be wrapped as MaxwellSolution(model, omega, u) and evaluated with field_values.

The PDESystem is the time-domain equation for a vector unknown E with spaces = Dict(E => Nedelec{RefTetrahedron, 1}()),

curl(ν curl E) + a₂ ∂ₜ²E + a₁ ∂ₜE + a₀ E = f,

one equation per component, written with curl. ν, a₀, a₁ and a₂ are real scalar functions of the coordinates and parameters, and the source f(x) is read as the phasor amplitude of exp(+iωt). Each cell gets MaxwellMaterial(eps_r = a₂ - a₀/ω², mu_r = 1/ν, sigma = a₁) sampled at its centroid, with eps0 = mu0 = length_scale = 1, so the system is Kc - ω² Mε + iω Mσ of the model and the load is ∫ f ⋅ Nᵢ. A complex permittivity has no real time-domain form here; build a MaxwellModel directly for it.

With n = facet_normal(Γ) and Eb = [E(t, Γ)[c] for c in 1:3], the boundary conditions on a piece Γ are

  • the perfect conductor cross(n, Eb) .~ 0, the model's pec;
  • the first-order absorbing (Silver-Müller) condition cross(n, ν * curl(Eb, X)) .~ -sqrt(ε / μ) .* cross(n, cross(n, Dt.(Eb))), with ε = a₂ and ν = 1/μ of the cells next to Γ, the model's absorbing. Dt becomes iω, so this is the model's n × (μr⁻¹ ∇ × E) = -i k0 sqrt(εr/μr) n × (n × E) with k0 = ω. Any equivalent set of equations is accepted (a multiple, the other cross order, a linear combination): at every facet the conditions must span exactly the two tangential equations of this one. The cells next to Γ must be lossless (a₁ = a₀ = 0); a mismatched coefficient, impedance or sign is an error, since the model implements only the matched condition.

Pieces without a condition get the natural n × (ν curl E) = 0, except those carrying the WavePorts of disc.ports, which must have no condition. With ports, a₀ must be zero, so that the model holds at every frequency and solve_sweep(model, omegas) is the sweep of the PDESystem.

Operator level

FiniteElementMethod.MaxwellModel — Type
MaxwellModel(grid; materials = Dict(), pec = String[], absorbing = String[], ports = WavePort[],
             length_scale = 1.0, eps0 = EPS0, mu0 = MU0, quadrature = 2)

The time-harmonic electric-field model on a Ferrite grid of Tetrahedron cells, with the field :E in Nedelec{RefTetrahedron, 1}. The equation, for fields varying as exp(+iωt), is

∇ × (μr⁻¹ ∇ × E) + iωμ0 σ E - ω² μ0 ε0 εr E = -iωμ0 J,

with n × E = 0 on the facet sets named in pec and the natural condition n × (μr⁻¹ ∇ × E) = 0 on the rest of the boundary, except for the facet sets named in absorbing, which carry the first-order Silver-Müller absorbing condition n × (μr⁻¹ ∇ × E) = -i k0 sqrt(εc/μr) n × (n × E) with εc = εr - iσ/(ωε0), and the WavePorts in ports.

materials maps cell set names of grid (as FerriteGmsh.togrid makes from Gmsh physical groups) to MaxwellMaterials; cells in no named set are vacuum, and a cell in two named sets is an error. It may also be a vector of MaxwellMaterials, one per cell of grid in cell order. Mesh coordinates are in units of length_scale metres. eps0 and mu0 default to their SI values; eps0 = mu0 = 1 with length_scale = 1 gives normalised units with c = 1.

Galerkin discretisation divided through by length_scale (L) gives A(ω) u = b, where A is a sum of real sparse blocks on one sparsity pattern, each with a complex coefficient that is a function of ω:

A(ω) = Kc - ω² μ0 ε0 L² (Mε' + i Mε'') + iω μ0 L² Mσ,

Kc = ∫ μr⁻¹ ∇×Nᵢ ⋅ ∇×Nⱼ, Mε' = ∫ Re(εr) Nᵢ⋅Nⱼ, Mε'' = ∫ Im(εr) Nᵢ⋅Nⱼ and Mσ = ∫ σ Nᵢ⋅Nⱼ over the mesh (so Im(εr) = -ε'' gives the +iω²μ0ε0L² ε'' loss term). The absorbing boundary adds +i k0 L ∮ sqrt(εc/μr) (n × Nᵢ)⋅(n × Nⱼ) dS (k0 = ω sqrt(μ0 ε0), material of the adjacent cell) and each wave port +i (β(ω)/μr) L ∮ (n × Nᵢ)⋅(n × Nⱼ) dS over its face. A is complex symmetric, not Hermitian.

Fields: grid, dh, ch (zero AffineConstraints on the PEC edge dofs), cellvalues, materials (one per cell), pec, eps0, mu0, length_scale, blocks (the volume blocks curlcurl, eps_real, eps_imag and sigma above), absorbing, ports (the FiniteElementMethod.WavePortData in the order given) and terms, the MaxwellTerms that maxwell_operator! combines; FiniteElementMethod.add_term! appends further blocks, such as boundary terms.

FiniteElementMethod.driven_problem — Function
driven_problem(model::MaxwellModel, ω, J)

The SciMLBase LinearProblem A(ω) u = b of MaxwellModel at angular frequency ω (rad/s) with current density J (as for FiniteElementMethod.maxwell_rhs) and the PEC constraints applied by Ferrite's apply!: the constrained rows and columns are zeroed with a nonzero diagonal, which keeps A complex symmetric. Its solution u are the edge dofs of E; wrap them with MaxwellSolution(model, ω, u) to evaluate the field.

driven_problem(model::MaxwellModel, ω; load)

The LinearProblem A(ω) u = load as for driven_problem(model, ω, J), with the load vector given directly instead of from a current density: load is indexed by the dofs of model.dh, holds ∫ f ⋅ Nᵢ for a source f of the equation divided through as in MaxwellModel, and is copied before the PEC constraints are applied.

FiniteElementMethod.WavePort — Type
WavePort(facetset; a_direction, e_direction = nothing, deembed = 0.0)

A TE10 wave port of a rectangular waveguide on the planar boundary facet set facetset of a MaxwellModel. The port face must be the full guide cross-section, a rectangle with PEC on its rim, filled with one lossless-or-dielectric material (no conductivity).

a_direction is a vector along the broad wall (the side of length a); the mode is e = ê sin(π ξ / a), with ξ the distance from the edge of the rectangle along a_direction and ê the in-plane unit vector perpendicular to it. By default ê is n × â with its sign chosen so that its largest Cartesian component is positive, which gives both ends of a straight guide the same polarisation; pass e_direction to fix it explicitly. deembed moves the reference plane of the port a distance (in mesh units) from the port face into the device.

source
FiniteElementMethod.WavePortData — Type
WavePortData

A WavePort assembled on a MaxwellModel, in model.ports. Fields: port, block (the tangential mass ∮ (n × Nᵢ)⋅(n × Nⱼ) dS of the port face), profile (pᵢ = ∮ e⋅Nᵢ dS), norm (pᵀ B⁻¹ p over the unconstrained edge dofs of the face: ∮ e_h⋅e_h dS of the L² projection e_h of the mode onto the discrete tangential traces, so that a port-face field c e_h gives exactly pᵀu / norm = c), normal (outward), a, b (mesh units), kc (π / (a L), rad/m), eps_r and mu_r of the port material.

FiniteElementMethod.solve_sweep — Function
solve_sweep(model::MaxwellModel, omegas; fields = false, solver = umfpack_solver)

The scattering matrix of the WavePorts of model at each angular frequency in omegas (rad/s), as a MaxwellSweep. Each frequency recombines the nonzero values of one operator matrix with maxwell_operator!, applies the PEC constraints, and solves for all port excitations at once with solver(A, B, cache) (see FiniteElementMethod.umfpack_solver), which may keep its factorisation between frequencies in cache. fields = true keeps the solutions (ndofs × nports complex values per frequency).

source
solve_sweep(pdesys::PDESystem, disc::FEMDiscretization, omegas; kwargs...)

The wave-port scattering matrices of the PDESystem at the angular frequencies omegas: solve_sweep of the model of maxwell_model(pdesys, disc), which disc.ports drive. The PDESystem must have no source, since the sweep excites the ports only; disc.omega builds the model but does not enter the result.

MaxwellSweep
