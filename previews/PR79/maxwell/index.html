Frequency-domain Maxwell

MaxwellModel is a separate entry point from the PDESystem front end: it assembles the time-harmonic electric-field equation directly with Ferrite, using lowest-order Nédélec edge elements (Nedelec{RefTetrahedron, 1}) on a tetrahedral mesh. With fields varying as exp(+iωt), it solves

\[\nabla \times \left(\mu_r^{-1} \nabla \times \mathbf{E}\right) + i\omega\mu_0\sigma\mathbf{E} - \omega^2\mu_0\varepsilon_0\varepsilon_r\mathbf{E} = -i\omega\mu_0\mathbf{J},\]

with n × E = 0 on the perfectly conducting (PEC) facet sets. Materials are assigned per cell set, as FerriteGmsh.togrid produces them from Gmsh physical groups; unnamed cells are vacuum. A passive lossy dielectric has εr = ε' - iε'' with ε'' ≥ 0.

using FiniteElementMethod, Ferrite
grid = generate_grid(Tetrahedron, (8, 8, 8), Vec(0.0, 0.0, 0.0), Vec(1.0, 1.0, 1.0))
addcellset!(grid, "substrate", x -> x[3] <= 0.25)
model = MaxwellModel(
    grid; materials = Dict("substrate" => MaxwellMaterial(; eps_r = 4.4 - 0.08im)),
    pec = ["left", "right", "bottom", "top", "front", "back"], length_scale = 1.0e-2,  # mesh in cm
)
sol = solve_driven(model, 2π * 5.0e9, x -> [0.0, 0.0, exp(-sum(abs2, x .- 0.5) / 0.01)])
field_values(sol, [Vec(0.5, 0.5, 0.5)]).E

The system matrix is a sum of real sparse blocks on one sparsity pattern, each with a complex coefficient that is a function of ω, so a frequency sweep only recombines nonzero values with maxwell_operator!, and further terms (boundary conditions, ports) are added as blocks with FiniteElementMethod.add_term!.

Wave ports, absorbing boundaries and frequency sweeps

Rectangular-waveguide ports and first-order absorbing boundaries are model keywords. A WavePort on a planar boundary facet set launches and absorbs the TE10 mode of the rectangle it spans; a_direction names the broad wall. Facet sets in absorbing get the first-order Silver-Müller condition n × (μr⁻¹ ∇ × E) = -i k0 sqrt(εc/μr) n × (n × E) (εc = εr - iσ/(ωε0) of the adjacent material), exact for a plane wave at normal incidence (a TE10 wave reflects Γ = (β - k0)/(β + k0) from it). solve_sweep returns the scattering matrix at each angular frequency; it keeps one operator matrix and one factorisation pattern, and solves every port's excitation from a single factorisation per frequency. The linear solver is the solver keyword (see FiniteElementMethod.umfpack_solver).

using FiniteElementMethod, Ferrite
# A 50 mm section of WR-90 (22.86 mm × 10.16 mm), mesh in millimetres.
grid = generate_grid(Tetrahedron, (16, 7, 34), Vec(0.0, 0.0, 0.0), Vec(22.86, 10.16, 50.0))
ports = [WavePort("bottom"; a_direction = (1, 0, 0)), WavePort("top"; a_direction = (1, 0, 0))]
model = MaxwellModel(grid; pec = ["left", "right", "front", "back"], ports, length_scale = 1.0e-3)
sweep = solve_sweep(model, 2π .* (8.0e9:0.5e9:12.0e9))
sweep.S[2, 1, 5]  # S21 at 10 GHz: |S21| ≈ 1, angle ≈ -93.3°

Sᵢⱼ is referred to the port faces, or to planes deembed mesh units inside them. Ports on different guides are normalised to power waves through the TE10 wave impedance ωμ0μr/β. Below cutoff the propagation constant is β = -iα, the evanescent branch.

Lumped ports

A LumpedPort is a rectangular facet sheet bridging a gap between two conductors, of length l along direction and width w across it, on the boundary or inside the mesh. It carries a uniform sheet current I/w along direction; its voltage is the sheet average of the line integral of E across the gap, V = (1/w) ∮ E⋅l̂ dS. Every port is loaded by its reference impedance Z0, which adds iωμ0 L/(w² Z0) g gᵀ (gᵢ = ∮ l̂⋅Nᵢ dS) to the operator, and the driven port adds a 1 A current source in parallel, so Sᵢⱼ = 2Vᵢ/sqrt(Z0ᵢZ0ⱼ) - δᵢⱼ. Because the load, the source and the voltage use the same g, these circuit identities hold exactly for the discrete system: a lossless structure gives a unitary S. Wave and lumped ports can share one model and one sweep, both normalised to power waves.

using FiniteElementMethod, Ferrite
# A parallel-plate line (PEC plates at y = 0 and y = 5 mm, open sides) with a 50 Ω port at each end.
grid = generate_grid(Tetrahedron, (2, 2, 20), Vec(0.0, 0.0, 0.0), Vec(10.0, 5.0, 20.0))
ports = [LumpedPort("bottom"; direction = (0, 1, 0)), LumpedPort("top"; direction = (0, 1, 0))]
model = MaxwellModel(grid; pec = ["front", "back"], ports, length_scale = 1.0e-3)
S = solve_sweep(model, [2π * 3.0e9]).S[:, :, 1]  # S11 ≈ 0.846 + 0.136i, S21 ≈ 0.082 - 0.508i
Z = FiniteElementMethod.z_parameters(model, S)

The port couples all its edge dofs to each other, which widens the sparsity pattern, so keep the sheet a few elements across.

FiniteElementMethod.MaxwellModel — Type
MaxwellModel(grid; materials = Dict(), pec = String[], absorbing = String[], ports = [],
             length_scale = 1.0, eps0 = EPS0, mu0 = MU0, quadrature = 2)

The time-harmonic electric-field model on a Ferrite grid of Tetrahedron cells, with the field :E in Nedelec{RefTetrahedron, 1}. The equation, for fields varying as exp(+iωt), is

∇ × (μr⁻¹ ∇ × E) + iωμ0 σ E - ω² μ0 ε0 εr E = -iωμ0 J,

with n × E = 0 on the facet sets named in pec and the natural condition n × (μr⁻¹ ∇ × E) = 0 on the rest of the boundary, except for the facet sets named in absorbing, which carry the first-order Silver-Müller absorbing condition n × (μr⁻¹ ∇ × E) = -i k0 sqrt(εc/μr) n × (n × E) with εc = εr - iσ/(ωε0), and the WavePorts and LumpedPorts in ports, numbered in the order given.

materials maps cell set names of grid (as FerriteGmsh.togrid makes from Gmsh physical groups) to MaxwellMaterials; cells in no named set are vacuum, and a cell in two named sets is an error. Mesh coordinates are in units of length_scale metres. eps0 and mu0 default to their SI values; eps0 = mu0 = 1 with length_scale = 1 gives normalised units with c = 1.

Galerkin discretisation divided through by length_scale (L) gives A(ω) u = b, where A is a sum of real sparse blocks on one sparsity pattern, each with a complex coefficient that is a function of ω:

A(ω) = Kc - ω² μ0 ε0 L² (Mε' + i Mε'') + iω μ0 L² Mσ,

Kc = ∫ μr⁻¹ ∇×Nᵢ ⋅ ∇×Nⱼ, Mε' = ∫ Re(εr) Nᵢ⋅Nⱼ, Mε'' = ∫ Im(εr) Nᵢ⋅Nⱼ and Mσ = ∫ σ Nᵢ⋅Nⱼ over the mesh (so Im(εr) = -ε'' gives the +iω²μ0ε0L² ε'' loss term). The absorbing boundary adds +i k0 L ∮ sqrt(εc/μr) (n × Nᵢ)⋅(n × Nⱼ) dS (k0 = ω sqrt(μ0 ε0), material of the adjacent cell) and each wave port +i (β(ω)/μr) L ∮ (n × Nᵢ)⋅(n × Nⱼ) dS over its face; each lumped port adds +iω μ0 L / (w² Z0) g gᵀ (see FiniteElementMethod.LumpedPortData), whose dof pairs widen the cell-based sparsity pattern. A is complex symmetric, not Hermitian.

Fields: grid, dh, ch (zero AffineConstraints on the PEC edge dofs), cellvalues, materials (one per cell), pec, eps0, mu0, length_scale, blocks (the volume blocks curlcurl, eps_real, eps_imag and sigma above), absorbing, ports (the FiniteElementMethod.WavePortData and FiniteElementMethod.LumpedPortData in the order given) and terms, the MaxwellTerms that maxwell_operator! combines; FiniteElementMethod.add_term! appends further blocks, such as boundary terms.

FiniteElementMethod.MaxwellMaterial — Type
MaxwellMaterial(; eps_r = 1, mu_r = 1, sigma = 0)

An isotropic linear material: relative permittivity eps_r = ε' - iε'' (real or complex; with the exp(+iωt) convention a passive medium has ε'' ≥ 0), real relative permeability mu_r and conductivity sigma in S/m. The default is vacuum.

FiniteElementMethod.maxwell_operator! — Function
maxwell_operator!(A, model::MaxwellModel, ω)

Overwrite the nonzero values of the complex sparse matrix A, which must have the sparsity pattern of model.blocks, with Σₖ cₖ(ω) Bₖ over the MaxwellTerms of model. No constraints are applied.

FiniteElementMethod.driven_problem — Function
driven_problem(model::MaxwellModel, ω, J)

The SciMLBase LinearProblem A(ω) u = b of MaxwellModel at angular frequency ω (rad/s) with current density J (as for FiniteElementMethod.maxwell_rhs) and the PEC constraints applied by Ferrite's apply!: the constrained rows and columns are zeroed with a nonzero diagonal, which keeps A complex symmetric. Its solution u are the edge dofs of E; wrap them with MaxwellSolution(model, ω, u) to evaluate the field.

FiniteElementMethod.WavePort — Type
WavePort(facetset; a_direction, e_direction = nothing, deembed = 0.0)

A TE10 wave port of a rectangular waveguide on the planar boundary facet set facetset of a MaxwellModel. The port face must be the full guide cross-section, a rectangle with PEC on its rim, filled with one lossless-or-dielectric material (no conductivity).

a_direction is a vector along the broad wall (the side of length a); the mode is e = ê sin(π ξ / a), with ξ the distance from the edge of the rectangle along a_direction and ê the in-plane unit vector perpendicular to it. By default ê is n × â with its sign chosen so that its largest Cartesian component is positive, which gives both ends of a straight guide the same polarisation; pass e_direction to fix it explicitly. deembed moves the reference plane of the port a distance (in mesh units) from the port face into the device.

source
FiniteElementMethod.WavePortData — Type
WavePortData

A WavePort assembled on a MaxwellModel, in model.ports. Fields: port, block (the tangential mass ∮ (n × Nᵢ)⋅(n × Nⱼ) dS of the port face), profile (pᵢ = ∮ e⋅Nᵢ dS), norm (pᵀ B⁻¹ p over the unconstrained edge dofs of the face: ∮ e_h⋅e_h dS of the L² projection e_h of the mode onto the discrete tangential traces, so that a port-face field c e_h gives exactly pᵀu / norm = c), normal (outward), a, b (mesh units), kc (π / (a L), rad/m), eps_r and mu_r of the port material.

FiniteElementMethod.LumpedPort — Type
LumpedPort(facetset; direction, Z0 = 50.0)

A lumped port on the planar facet set facetset of a MaxwellModel: a rectangular sheet of length l along direction (in the sheet plane, from one conductor to the other) and width w across it, bridging a gap. The sheet may lie on the boundary or inside the mesh; a facet listed from both of its cells counts once.

The port carries a uniform sheet current I / w along direction, so the gap voltage is the sheet average of the line integral of E along direction, V = (1/w) ∮ E⋅l̂ dS (positive when the start of direction is the + terminal). Every port is loaded by its real reference impedance Z0 (ohm) and the driven port adds a 1 A current source in parallel (see FiniteElementMethod.port_excitations). The port couples all of its edge dofs to each other, so keep the sheet a few elements across.

source
FiniteElementMethod.LumpedPortData — Type
LumpedPortData

A LumpedPort assembled on a MaxwellModel, in model.ports. Fields: port, profile (gᵢ = ∮ l̂⋅Nᵢ dS over the sheet, so that V = L gᵀu / w), dofs (the edge dofs of the sheet), block (g gᵀ on the model's sparsity pattern), normal, length and width (l and w, mesh units).

FiniteElementMethod.z_parameters — Function
z_parameters(model::MaxwellModel, S)

The impedance matrix (ohm) Z = G^½ (I + S)(I - S)⁻¹ G^½, G = diag(Z0), of a scattering matrix S of a model whose ports are all lumped ports, inverting Sᵢⱼ = 2 Vᵢ / sqrt(Z0ᵢ Z0ⱼ) - δᵢⱼ for a 1 A source at port j.

FiniteElementMethod.solve_sweep — Function
solve_sweep(model::MaxwellModel, omegas; fields = false, solver = umfpack_solver)

The scattering matrix of the WavePorts and LumpedPorts of model at each angular frequency in omegas (rad/s), as a MaxwellSweep. Each frequency recombines the nonzero values of one operator matrix with maxwell_operator!, applies the PEC constraints, and solves for all port excitations at once with solver(A, B, cache) (see FiniteElementMethod.umfpack_solver), which may keep its factorisation between frequencies in cache. fields = true keeps the solutions (ndofs × nports complex values per frequency).

source
FiniteElementMethod.MaxwellSweep — Type
MaxwellSweep

The result of solve_sweep: omegas, the scattering matrices S[:, :, k] at omegas[k] (S[i, j, k] is the power wave leaving port i for a unit power wave incident on port j) and fields, either nothing or, per frequency, the matrix whose column j is the edge-dof vector with port j driven (wrap it with MaxwellSolution(model, omegas[k], fields[k][:, j])).

source
FiniteElementMethod.umfpack_solver — Function
umfpack_solver(A, B, cache) -> (X, cache)

The default linear solver of solve_sweep: an UMFPACK LU factorisation of A, reusing the symbolic analysis of the previous frequency (cache, nothing on the first call) since the pattern never changes, applied to all columns of B. A replacement solver has the same signature.

The load vectors of the ports of model at ω, one column per port, without the PEC constraints: for a wave port the TE10 mode of unit amplitude (1 V/m) incident on it, for a lumped port a 1 A current source in parallel with its Z0.

FiniteElementMethod.s_parameters — Function
s_parameters(model::MaxwellModel, ω, U)

The scattering matrix Sᵢⱼ = bᵢ / aⱼ from the solutions U[:, j] with port j driven by port_excitations, in power waves. A wave port has aⱼ = sqrt(Pⱼ / Zⱼ) exp(-iβⱼdⱼ) and bᵢ = (pᵢᵀuⱼ / Pᵢ - δᵢⱼ) sqrt(Pᵢ / Zᵢ) exp(iβᵢdᵢ), with Pᵢ = ∮ e⋅e dS, the TE10 wave impedance Zᵢ = ωμ0μr / βᵢ and the de-embedding distances dᵢ. A lumped port has aⱼ = sqrt(Z0ⱼ) / 2 and bᵢ = (2Vᵢ - Z0ᵢ δᵢⱼ) / (2 sqrt(Z0ᵢ)), so between lumped ports Sᵢⱼ = 2Vᵢ / sqrt(Z0ᵢ Z0ⱼ) - δᵢⱼ.

source
