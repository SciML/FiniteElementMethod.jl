Frequency-domain Maxwell

MaxwellModel is a separate entry point from the PDESystem front end: it assembles the time-harmonic electric-field equation directly with Ferrite, using lowest-order Nédélec edge elements (Nedelec{RefTetrahedron, 1}) on a tetrahedral mesh. With fields varying as exp(+iωt), it solves

\[\nabla \times \left(\mu_r^{-1} \nabla \times \mathbf{E}\right) + i\omega\mu_0\sigma\mathbf{E} - \omega^2\mu_0\varepsilon_0\varepsilon_r\mathbf{E} = -i\omega\mu_0\mathbf{J},\]

with n × E = 0 on the perfectly conducting (PEC) facet sets. Materials are assigned per cell set, as FerriteGmsh.togrid produces them from Gmsh physical groups; unnamed cells are vacuum. A passive lossy dielectric has εr = ε' - iε'' with ε'' ≥ 0.

using FiniteElementMethod, Ferrite
grid = generate_grid(Tetrahedron, (8, 8, 8), Vec(0.0, 0.0, 0.0), Vec(1.0, 1.0, 1.0))
addcellset!(grid, "substrate", x -> x[3] <= 0.25)
model = MaxwellModel(
    grid; materials = Dict("substrate" => MaxwellMaterial(; eps_r = 4.4 - 0.08im)),
    pec = ["left", "right", "bottom", "top", "front", "back"], length_scale = 1.0e-2,  # mesh in cm
)
sol = solve_driven(model, 2π * 5.0e9, x -> [0.0, 0.0, exp(-sum(abs2, x .- 0.5) / 0.01)])
field_values(sol, [Vec(0.5, 0.5, 0.5)]).E

The system matrix is a sum of real sparse blocks on one sparsity pattern, each with a complex coefficient that is a function of ω, so a frequency sweep only recombines nonzero values with maxwell_operator!, and further terms (boundary conditions, ports) are added as blocks with FiniteElementMethod.add_term!.

From a PDESystem

FEMDiscretization(Ω, t; omega, spaces = Dict(E => Nedelec{RefTetrahedron, 1}())) discretizes the time-domain equation curl(ν curl E) + a₂ ∂ₜ²E + a₁ ∂ₜE + a₀ E = f for a vector unknown E at the angular frequency omega, and discretize returns the complex LinearProblem that driven_problem builds for the equivalent MaxwellModel (in units with ε0 = μ0 = 1). The operator is written with curl and the perfect conductor with facet_normal.

using FiniteElementMethod, Ferrite, ModelingToolkit, LinearAlgebra, LinearSolve
grid = generate_grid(Tetrahedron, (8, 8, 8), Vec(0.0, 0.0, 0.0), Vec(1.0, 1.0, 1.0))
Ω = MeshDomain(grid)
@parameters x y z t
@variables E(..)[1:3]
X, Ev, Dt = (x, y, z), [E(t, x, y, z)[c] for c in 1:3], Differential(t)
cc = curl(curl(Ev, X) / 2, X)    # μr = 2
eqs = [cc[c] + 4 * Dt(Dt(Ev[c])) + 0.1 * Dt(Ev[c]) ~ (c == 3) * exp(-10 * ((x - 0.5)^2 + (y - 0.5)^2)) for c in 1:3]
pec = reduce(vcat, [cross(facet_normal(Γ), [E(t, Γ)[c] for c in 1:3]) .~ 0 for Γ in boundarypieces(Ω)])
@named sys = PDESystem(eqs, pec, [t ∈ Interval(0.0, 1.0), (x, y, z) ∈ Ω], [t, x, y, z], [E(t, x, y, z)])
disc = FEMDiscretization(Ω, t; omega = 2.0, spaces = Dict(E => Nedelec{RefTetrahedron, 1}()))
sol = solve(discretize(sys, disc))
(; model, omega) = maxwell_model(sys, disc)
field_values(MaxwellSolution(model, omega, sol.u), [Vec(0.5, 0.5, 0.5)]).E

Coefficients are real, so a complex permittivity ε' - iε'' is only available on the operator-level MaxwellModel. Absorbing boundaries and ports are not yet part of the PDESystem path.

Tensors.curl — Method
curl(F, (x, y, z))

The curl ∇ × F of the 3-vector of symbolic expressions F in the coordinates (x, y, z), as a vector of Differential expressions, for writing the Maxwell operator in a PDESystem: curl(curl(E(t, x, y, z), (x, y, z)) / μ, (x, y, z)). This is a method of Ferrite's (Tensors') curl, which FiniteElementMethod re-exports, so that loading both packages leaves one curl.

FiniteElementMethod.facet_normal — Function
facet_normal(Γ::BoundaryPiece)

The symbolic outward unit normal of the boundary piece Γ, as a vector of its three components, for boundary conditions such as the perfect conductor cross(facet_normal(Γ), [E(t, Γ)[c] for c in 1:3]) .~ 0. It is PDEBase.normal(Γ) where PDEBase defines it (SciML/PDEBase.jl#164) and a term of this package otherwise; the name avoids DomainSets' own exported normal. The normal itself is read off the facets of the mesh.

FiniteElementMethod.maxwell_model — Function
maxwell_model(pdesys::PDESystem, disc::FEMDiscretization) -> (; model, omega, load)

The MaxwellModel, angular frequency and load vector that discretize(pdesys, disc) builds for a disc with omega, so that the solution u of its LinearProblem can be wrapped as MaxwellSolution(model, omega, u) and evaluated with field_values.

The PDESystem is the time-domain equation for a vector unknown E with spaces = Dict(E => Nedelec{RefTetrahedron, 1}()),

curl(ν curl E) + a₂ ∂ₜ²E + a₁ ∂ₜE + a₀ E = f,

one equation per component, written with curl. ν, a₀, a₁ and a₂ are real scalar functions of the coordinates and parameters, and the source f(x) is read as the phasor amplitude of exp(+iωt). Each cell gets MaxwellMaterial(eps_r = a₂ - a₀/ω², mu_r = 1/ν, sigma = a₁) sampled at its centroid, with eps0 = mu0 = length_scale = 1, so the system is Kc - ω² Mε + iω Mσ of the model and the load is ∫ f ⋅ Nᵢ. Boundary conditions are the perfect conductor cross(facet_normal(Γ), [E(t, Γ)[c] for c in 1:3]) .~ 0; pieces without a condition get the natural n × (ν curl E) = 0. A complex permittivity has no real time-domain form here; build a MaxwellModel directly for it.

Operator level

FiniteElementMethod.MaxwellModel — Type
MaxwellModel(grid; materials = Dict(), pec = String[], length_scale = 1.0, eps0 = EPS0, mu0 = MU0,
             quadrature = 2)

The time-harmonic electric-field model on a Ferrite grid of Tetrahedron cells, with the field :E in Nedelec{RefTetrahedron, 1}. The equation, for fields varying as exp(+iωt), is

∇ × (μr⁻¹ ∇ × E) + iωμ0 σ E - ω² μ0 ε0 εr E = -iωμ0 J,

with n × E = 0 on the facet sets named in pec and the natural condition n × (μr⁻¹ ∇ × E) = 0 on the rest of the boundary.

materials maps cell set names of grid (as FerriteGmsh.togrid makes from Gmsh physical groups) to MaxwellMaterials; cells in no named set are vacuum, and a cell in two named sets is an error. It may also be a vector of MaxwellMaterials, one per cell of grid in cell order. Mesh coordinates are in units of length_scale metres. eps0 and mu0 default to their SI values; eps0 = mu0 = 1 with length_scale = 1 gives normalised units with c = 1.

Galerkin discretisation divided through by length_scale (L) gives A(ω) u = b, where A is a sum of real sparse blocks on one sparsity pattern, each with a complex coefficient that is a function of ω:

A(ω) = Kc - ω² μ0 ε0 L² (Mε' + i Mε'') + iω μ0 L² Mσ,

Kc = ∫ μr⁻¹ ∇×Nᵢ ⋅ ∇×Nⱼ, Mε' = ∫ Re(εr) Nᵢ⋅Nⱼ, Mε'' = ∫ Im(εr) Nᵢ⋅Nⱼ and Mσ = ∫ σ Nᵢ⋅Nⱼ over the mesh (so Im(εr) = -ε'' gives the +iω²μ0ε0L² ε'' loss term). A is complex symmetric, not Hermitian.

Fields: grid, dh, ch (zero AffineConstraints on the PEC edge dofs), cellvalues, materials (one per cell), pec, eps0, mu0, length_scale, blocks (the volume blocks curlcurl, eps_real, eps_imag and sigma above) and terms, the MaxwellTerms that maxwell_operator! combines; FiniteElementMethod.add_term! appends further blocks, such as boundary terms.

FiniteElementMethod.MaxwellMaterial — Type
MaxwellMaterial(; eps_r = 1, mu_r = 1, sigma = 0)

An isotropic linear material: relative permittivity eps_r = ε' - iε'' (real or complex; with the exp(+iωt) convention a passive medium has ε'' ≥ 0), real relative permeability mu_r and conductivity sigma in S/m. The default is vacuum.

FiniteElementMethod.MaxwellTerm — Type
MaxwellTerm(block, coefficient)

One term coefficient(ω) * block of the system matrix of a MaxwellModel: block is a real sparse matrix on the model's sparsity pattern and coefficient maps the angular frequency to a complex number.

FiniteElementMethod.maxwell_operator — Function
maxwell_operator(model::MaxwellModel, ω)

The complex symmetric system matrix A(ω) of MaxwellModel, without the PEC constraints, as a new SparseMatrixCSC{ComplexF64} on the pattern of model.blocks.

source
FiniteElementMethod.maxwell_operator! — Function
maxwell_operator!(A, model::MaxwellModel, ω)

Overwrite the nonzero values of the complex sparse matrix A, which must have the sparsity pattern of model.blocks, with Σₖ cₖ(ω) Bₖ over the MaxwellTerms of model. No constraints are applied.

source
FiniteElementMethod.driven_problem — Function
driven_problem(model::MaxwellModel, ω, J)

The SciMLBase LinearProblem A(ω) u = b of MaxwellModel at angular frequency ω (rad/s) with current density J (as for FiniteElementMethod.maxwell_rhs) and the PEC constraints applied by Ferrite's apply!: the constrained rows and columns are zeroed with a nonzero diagonal, which keeps A complex symmetric. Its solution u are the edge dofs of E; wrap them with MaxwellSolution(model, ω, u) to evaluate the field.

source
driven_problem(model::MaxwellModel, ω; load)

The LinearProblem A(ω) u = load as for driven_problem(model, ω, J), with the load vector given directly instead of from a current density: load is indexed by the dofs of model.dh, holds ∫ f ⋅ Nᵢ for a source f of the equation divided through as in MaxwellModel, and is copied before the PEC constraints are applied.

source

solve_driven(model::MaxwellModel, ω, J)

Solve driven_problem with a sparse direct factorisation and return the MaxwellSolution.

FiniteElementMethod.MaxwellSolution — Type
MaxwellSolution(model, omega, u)

The electric field of a MaxwellModel at angular frequency omega: u is the complex vector of Nedelec edge dofs in the order of model.dh. Evaluate it at points with field_values.

FiniteElementMethod.field_values — Function
field_values(sol::MaxwellSolution, points)

(; E, curlE) at the mesh-coordinate points (Vec{3}s): vectors of Vec{3, ComplexF64}, with curlE in SI units (per metre, not per mesh unit). Points outside the mesh get NaNs.

source
FiniteElementMethod.maxwell_rhs — Function
maxwell_rhs(model::MaxwellModel, ω, J)

The load vector b = -iωμ0 L² ∫ J ⋅ Nᵢ of MaxwellModel for the current density J in A/m², without the PEC constraints. J is either a function of the mesh coordinate x::Vec{3} returning a 3-vector, or a dictionary from cell set names to constant 3-vectors (zero outside the named sets).

source

add_term!(model::MaxwellModel, block, coefficient)

Append the term coefficient(ω) * block to the system matrix of model. block must have the sparsity pattern of model.blocks, as every matrix from Ferrite.allocate_matrix(model.dh) does.
